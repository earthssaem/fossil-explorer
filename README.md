# 지층 탐사대: 사라진 시간을 이어라

고등학교 통합과학 「지질시대와 대멸종」 단원 복습용 도트 RPG 탐사 게임입니다.
빌드 도구 없이 정적 파일만으로 동작하므로 `index.html`을 열거나 아무 정적 호스팅에 올리면 됩니다.

## 지질 설정

- 가상의 지질공원. 북쪽으로 갈수록 지대가 높아지고, 지층은 아래에서 위로 쌓이므로
  남쪽 입구(선캄브리아 시대)에서 북쪽 전망대(신생대)로 걸어가면 더 젊은 지층을 차례로 만납니다.
- 단단한 층이 동서로 이어지는 절벽(계단식 지형)을 이루고, 구역 사이는 계단으로만 오르내립니다.
  계단의 관문은 앞 구역의 노두를 다 조사해야 열립니다.
- 강이 남북으로 흐르며 골짜기를 팠습니다. 노두(암석이나 지층이 지표에 드러난 곳)는 이 공원에서는 **강가 절벽**에 있으며,
  노두마다 그 구역의 지층과 아래층 윗부분이 드러나므로 6곳을 이어 붙여야 지층 기둥이 완성됩니다.
- 지층 A(스트로마톨라이트 / 에디아카라 생물군), F(참나무 잎 / 매머드), D(암모나이트 / 경계층 / 위층)는
  아래·위 띠로 나뉘어 있고, 변화를 시간 순서대로 보기 위해 아래층부터 조사합니다 (게임 진행 규칙).
- 지층 D 위층(경계층 바로 위)에서는 암모나이트가 더 이상 나오지 않고, 다른 종류의 작은 해양 생물 화석이
  한 지점에서만 드물게 나옵니다. 이 화석은 관찰 문장만 보여 주며 퀴즈·도감 카드가 없습니다 (대멸종 뒤에도 생물이 있었음을 보여 주는 용도).
- 최종 미션 1단계는 탐사에서 확인한 지층 기록 카드(시대·화석·환경)를 끌어 옮겨 오래된 것부터 차례로 배치하는 활동입니다.
  시대나 환경을 다시 묻지 않으며, 따로 조사한 기록을 하나의 지층 기둥으로 다시 연결하는 것이 목적입니다.
  2단계는 우리 공원 지층 기둥과 이름표 없는 이웃 마을 노두를 나란히 놓고, 같은 시대의 층끼리 끌어서 선으로 잇는
  지층 대비 활동입니다. 연결 대상은 삼엽충·공룡·고사리·경계층·화폐석·매머드 5개이며, 모두 이으면 바로 완료됩니다.
  산호층은 직접 잇지 않은 채 남고, 추가 문항이나 체크 항목은 없습니다. 층 두께는 지역마다 다르게 그리고,
  이웃 노두 아래에는 드러나지 않는 부분이 있습니다.
- 미니맵(탐사 지도)은 지층 분포도가 아니라 공원 탐사 구역 지도입니다. 6개 구역은 지형(풀·물·절벽·길)으로 구분하고,
  지층 A~F는 각 구역의 노두 마커(글자)로만 표시합니다. 구역 하나가 지층 하나가 아니라, 구역 안의 노두에서 그 지층을 조사합니다.
  (시대 이름은 학생이 추리해야 하므로 구역 이름·팻말·범례에 쓰지 않습니다.)

## 파일 구조

```
index.html            화면 뼈대
css/style.css         도트 RPG UI 스타일
js/data/items.js      ★ 화석·증거 아이템과 퀴즈 (교사 수정 영역)
js/data/layers.js     ★ 지층·배지·미션·탐사 노트·개념 태그 (교사 수정 영역)
js/data/world.js      ★ 지질공원 맵: 구역·절벽·관문·노두·길·소품·NPC 대사 (교사 수정 영역)
js/core/state.js      진행 상태 저장, 개념별 성취 집계, 다양성 집계, 데이터 점검, 효과음·시작 화면 배경음
js/core/sprites.js    화석·캐릭터 도트 스프라이트
js/core/dig.js        노두 조사창, 경계층 3단 잠금, 발굴, 발견·관찰
js/core/quiz.js       퀴즈, 도감 등록, 층 정보
js/core/mission.js    최종 미션(지층 기둥 완성 · 이웃 노두 대비 · 완료 화면), 보고서용 기둥 그리기
js/core/progress.js   HUD, 배지, 도감, 결과 화면, 제출용 보고서 PNG
js/world/tiles.js     타일셋·소품 스프라이트 생성 (코드로 그림, 외부 이미지 없음)
js/world/map.js       월드 생성, 충돌, 길찾기, 카메라, 렌더링, 탐사 구역 지도(미니맵), 상호작용
js/world/title.js     시작 화면 도트 배경 (구름·새·지층 절벽에 박힌 화석·걷는 탐사대원, 게임 타일 재사용)
js/ui.js              도트 아이콘, 대화창, 구역 배너, 화면 전환, 입력, 초기화
```

## 조작

- 이동: W·A·S·D 또는 방향키, 또는 목적지 클릭 (길을 따라 자동 이동)
- 조사·대화: E 또는 스페이스, 또는 대상 클릭
- 도감: M
- 모바일: 화면의 방향 버튼과 조사 버튼
- 진행 초기화: 시작 화면의 「처음부터 다시 시작」 또는 주소 뒤에 `?reset=1`
